往返机票都是错峰买的，所以相对便宜。在东京住的酒店是[一家位于人形町的胶囊酒店](https://ninehours.co.jp/zh-Hans/ningyocho)。这家酒店办理入住的时间是15点至次日5点，退房时间是11点前，需要注意的是酒店每天从11点到15点打扫胶囊仓区域，期间不能进入。个人认为此酒店适合整天在外面逛的游客。[在大阪住的酒店](https://www.booking.com/Share-3HGq9T)位于新今宫站、动物园前站附近，不管是搭乘JR、大阪地铁还是南海电铁都十分方便，房间品质不错，价格也比较便宜，非常推荐。

流量卡买的每天5G的，其实过于充裕了，每天3G就够了。

关于东京往大阪的新干线列车，正常刷西瓜卡随到随走花费一般是六百多。如果想省钱的话可以买站站乐列车，这种列车需要严格按照购买车次的时间、出发站与到达站乘坐，且需要一张信用卡支付费用。详细攻略可以参考[此处](https://xhslink.cn/o/4x137NRogP1)。

此外还有一点需要注意，不同于国内早已全面普及移动支付，日本依然在广泛使用现金进行支付，有的门店/景区甚至只接受现金。各位读者出行前务必带足现金，最好再办一张VISA/万事达信用卡以便支付或取现。笔者在日期间一共花费了大约一万八千円现金。

## 9.22 东京

| 284.89   | 二次元（Animate、AKIHABARA GAMERS 本店、骏河屋）       |
| 232.07   | 优衣库                        |

这里先简单谈谈东京的轨道交通，读者所能接触到的轨道交通主要有市区地铁（例如由东京Metro地铁、都营地下铁运营的13条线路，以及东京临海高速铁道等）、市域私铁（如去往横滨的东急东横线）与JR通勤铁路（如山手线）三类。除此之外，还有都电荒川线、日暮里-舍人线等低运量线路。笔者在这里购买的72h券只适用于市区地铁中由东京Metro地铁、都营地下铁运营的13条线路，不过这13条线路能够覆盖绝大多数热门地点。

笔者于当天早上到达东京，放好行李后在酒店附近找了一家拉面店。拉面除了较咸之外还不错，另外笔者还尝试了生鸡蛋配米饭，感觉也可以。吃完后，笔者就去秋叶原了。秋叶原不愧是知名圣地，非常地有氛围。笔者在秋叶原四处游走，买了不少东西 `还正好赶上了在 AKIHABARA GAMERS 本店的『藤都子展～16岁～』` 。之后笔者又去池袋的邦邦官店逛了逛，不过没有寻访到心仪的周边。

这之后笔者又回到秋叶原，在优衣库买了几件T恤 `顺带一提，读者如果有穿了很久的衣服不想要的，可以在日本穿过最后一次后直接丢掉，在优衣库进货` 。晚饭吃过烤肉和冷面后，笔者来到东京塔一带闲逛。然而由于步行许久，错过了地铁末班车，笔者只得购买JR车票回酒店。

## 9.23 东京



| 200.58   | 9.23合计                     |
| :------- | :------------------------- |
| 137.46   | 三明治+雨伞+晚饭                 |
| 25.14    | 二次元（骏河屋）                   |
| 37.98    | 浅草寺 抽签与钓纸鲷                 |

早上笔者去浅草寺，虽然略有小雨，好在并无大碍。下午笔者去涩谷塔店帮朋友买唱片。由于此前并未买过唱片，一直在店内环视四顾上下求索，加上昨天红眼航班的加成，笔者勉力买完后状态奇差，立刻回酒店睡觉了。

睡醒后已然日落，笔者先去秋叶原找寻朋友极力推荐的海鲜饭馆子『海之幸 翔』，然而到达后发现店门紧闭。后来笔者才发现这一天是日本的节假日。之后笔者接连找了两家馆子，才终于吃上饭。食罢，笔者又去了银座、浅草野游。

## 9.24 东京



| 450.66   | 9.24合计                     |

| 8.84     | JR                         |
| 21.81    | 买水、冰淇淋                     |

笔者早上又去了秋叶原，简单逛了逛此前没去的店铺后，便直奔海之幸 翔（其实闲逛主要是在等这家店开门）。结果到了门店发现老板自己给自己放假，节假日和周末之间的工作日 `即9.24，9.25` 也不营业。又白跑一趟。于是笔者换了一家馆子吃大腹套餐，感觉味道不错。

吃罢，笔者便往中野而去。中野的二次元店集中在中野百老汇内，主要以二手书/周边与古早书籍等为主。笔者主观评价其为夯。之后，笔者去往池袋，在池袋Animate大楼又买了几本书。池袋A店不止是世界最大的A店，更是吉尼斯认证的世界最大动画商品专卖店，馆藏非常之丰富，值得一看。

笔者晚饭是在日高屋吃的。此店主打中华料理特色，笔者并未尝出什么中国特色，不过此店性价比较高，也挺不错。吃完后，笔者开始在池袋云游。池袋分布着众多Mygo、Mujica的取景地，因此笔者进行了酣畅淋漓的圣地巡礼 `包括祥子痛哭之路口、『Soyorin』之称诞生地、c团K歌店、阳光城、成人桥、千世登小桥、面影桥等`。其中尤其值得一提的是阳光城顶楼的水族馆。此水族馆虽然坐落在闹市大楼之中，但是运营得相当不错，有着不少有趣的生物（比如室外区的企鹅，晚上七点前的企鹅池可以看到企鹅在头上游动的景象）。抛开爱灯圣地的buff，这家水族馆也是相当优秀，值得一去的。笔者到达水族馆时，正好赶上晚上的特别展，主题是关于各种生物的性交与繁衍。这个特别展也布置得很用心，可以说是值回票价了。

> 笔者全程使用[此网站](https://www.anitabi.cn/map)辅助圣地巡礼。此网站很好用，推荐。

## 9.25 横滨



| 462.35   | 9.25合计                     |
| :------- | :------------------------- |
| 38.64    | 东急东横+港未来一日券                   |
| 122.99   | 吃饭               |
| 13.86    | 买水                         |
| 265.86   | 二次元（骏河屋、Book off）          |
| 21.0     | 合味道博物馆门票                |

笔者早上在涩谷站买了东急东横+港未来一日券，凭此券可以往返涩谷站-横滨站一次，并无限次乘坐港未来线。到达横滨站在附近吃了一份煎鱼套餐后，笔者便在附近的骏河屋闲逛，搜刮到价格还不错的爱音娃娃以及一些素晴的文件夹。接着笔者便直奔合味道博物馆。此馆主要介绍安藤百福发明方便面，创办日清公司并做大做强的事迹。游览时建议先看看二楼的三堵泡面墙，然后去红色影厅看一段短片，再顺着影片末的指引去往安藤生平展的起点一路看着走。看完二楼内容后，可以上三楼体验自己制作一份杯面（不过笔者懒得动手没体验），也可以上四楼看台一览港未来地区的海景。

这之后笔者开始四处游走，途径万国桥、神奈川县厅、英国旧领事馆、横滨港等地 `也路过了红砖仓库，不过笔者没有走进去游览，只是远远拍了几张照` ，并逛了逛Book off，买到了好价手办。晚上笔者吃了顿寿司，便去往中华町游览。中华町的仿古建筑造的还有模有样的，整体风格偏向香港，也有点像民国上海滩，细细一看挺别致的。在中华町云游完后，笔者便回到了东京。

## 9.26 东京



| 176.97   | 9.26合计                     |
| :------- | :------------------------- |
| 73.25    | 东京自由通票                     |
| 73.19    | 吃饭（便利店三明治、日高屋）             |
| 8.82     | 买水                         |
| 9.24     | 地下铁博物馆门票                     |
| 21.29    | 东京国立博物馆门票                    |

笔者这一天买的自由通票相比9月22号的三日券乘坐范围更大，除了13条地铁线外还包括JR在都内的普通/快速车、都电荒川线、日暮里-舍人线与都营巴士。

此时笔者对日料的新鲜劲也过去了，也是直接用便利店三明治解决吃饭了。笔者先是去了地下铁博物馆。馆内首先映入眼帘的就是两节古早车厢，然后是关于东京地铁发展历史和一些机械部件、施工运营技术的介绍，最后走到头还有一个示意地下轨道网络交织的大模型。总的来说挺有意思，适合轨道交通迷来参观。之后，笔者来到皇居东御苑。东御苑感觉几乎就是一个普通的公园，而且在这个时节满眼只有绿色，只有四处散布的石头墙垒比较奇特。感觉不如新宿御苑和明治神宫，可惜没去。从东御苑出来后笔者又去武道馆拍了拍照。

此后笔者去了东京国立博物馆。博物馆的大学生半价可以用内地大学学生证，还不错。馆内藏品颇为丰富，一天还没逛完。之后笔者便去赤羽看北区花火会了。花火会分免费席和付费席（分别对应日语的無料席、有料席），然而笔者去之前没有了解到，加上花火大会的付费席一般也需要提前很久买，颇为抢手，只有去离花火燃放点更远的免费席。好在观看效果也不差，老日玩烟花确实很有创意，同时场内还会播放配套的音乐与朗诵 `可惜听不懂`。

看完后，笔者又开始了圣地巡礼。首先是正好也在赤羽的赤羽警署（动画里收容醉酒祥父之地），然后笔者乘车到达大塚站，沿都电荒川线寻访古迹，最终胜利抵达飞鸟山古战场。在飞鸟山拍了个爽之后，这一天的行程也就结束了。

笔者在这一天购买的小田急、江之电通票与25号的通票类似，可以坐一次新宿站-藤泽站往返，并可以无限次乘坐江之电。江之电个人感觉是比较奇特的，大部分区间都是单线，只在个别站点设置双线以供错车。这种情况下发车间隔长达13分钟，不过对于当地其实也够用了。此外，从腰越到七里滨的区间是基本平行于海岸线的，这一段电车与海景结合的风景相当不错。

笔者首先去了江之岛。从车站往江之岛的路上四处可见青春猪头少年新作上映的宣传旗 `顺带一提，藤泽、镰仓都是青猪的主阵地，结束乐队暑假团建去的亦正是江之岛。此外还有许多动画也以藤泽、镰仓为取景地` 。江之岛上有不少有趣的古迹，自然风光亦是一绝，而且在一些地方 `如边津宫附近的许愿牌悬挂处` 还能看到各路高手的画作，可谓是丰富多姿。

云游遍江之岛后笔者便往长谷寺、镰仓大佛赶去，然而由于笔者晚睡晚起，到达时已经不再放人进入。于是笔者只在长谷寺入口附近吃了一份抹茶冰淇淋。笔者吃的类型大抵是小红书上最吸睛的一类：蛋卷填上抹茶口味冰淇淋，再在上面覆盖一层抹茶色细丝状豆沙 `是的其实就是豆沙，带一些抹茶味，笔者起初刷到时以为也是冰淇淋，不过味道也不赖`。好在沿街的一些建筑也比较有特色，比如四条金吾邸址，算是个小众些的好去处。

此时也快要日落了，笔者决定在此时去海边看海景，因为当天天气其实不太行，比较阴沉，这种时候可以观赏晨昏交替之时的独特景观，比白天的时候更有看头。到达海滩之后，果然风景不错，正中下怀。观赏完后笔者去了鹤岗八幡宫。八幡宫的参道夹在通往八幡宫正门的大道中间，甚奇特。逛完晚上的八幡宫后，笔者又回到腰越附近，边走边欣赏彻底入夜后的海景，而后返回东京。

笔者在关西的主要行程是大阪周边的各县市，至于大阪本身，则只预留了最后一天。关西JR mini 3日券适用于指定范围的JR线路，只要在三天内每天都往返周边县市一次就能回本，非常划算。笔者在这一天去了神户。首先到达的是生田神社。神社比较小一会就能看完，御朱印所会售卖特定时节的特色章印，笔者就在此买了一份中秋特色的参拜章。

然后，笔者搭JR去了舞子。在笔者看来，舞子的主要看点在于明石海岸大桥，以及舞子公园内的孙文纪念馆。游览孙文纪念馆、旧武藤山治邸与旧木下家住宅可以买一张通票，不过笔者没有去更远的旧木下家住宅，只去了前两者，也能够回本。孙文纪念馆主要介绍孙中山的革命活动，馆藏实物主要是关于孙中山在日之活动，以及与日本人的交流。旧武藤山治邸则更偏重于建筑本身的观赏，因笔者对其人无甚兴趣。

之后笔者回到神户，在北野异人馆地区野游。『异人』在日语中指外国人（尤其是西洋人），但自明治时代后便被『外国人』所取代。此片区拥有密集的西洋建筑，这些建筑源于《美日修好通商条约》中开放神户、长崎兴建外国人居留地的规定。笔者购买通票参观了奥地利、丹麦、荷兰风格的异人馆，随后又四处闲逛，观赏其他的建筑。

观赏完已是傍晚，笔者进入市区品尝了神户牛，肉质爽滑肥嫩，很顶。吃完笔者又开始野游。先是到了南京町，这里跟横滨中华町相比就比较拉了，甚至牌楼的题字都比较丑。然后笔者到达神户港美利坚公园地带 `小有名气的 BE KOBE 标志就在此处` ，这里的夜景颇好，笔者在此云游许久。

京都的景观按理来说得花三天来逛，不过笔者就安排了一天，所以只挑了一些地方游览。

笔者首先去了涉成园，园内景致布置得还挺不错，不过时候还不太好，若是秋天红叶季的时候会更加好看。然后笔者去了旁边的东本愿寺。东本愿寺颇为宏大，外观的色彩风格大抵可以称为黑金配色 `日本很多古建都喜欢用深色甚至黑色的木头，比较奇特`，有一种肃穆之感。寺内的大堂相比外观金色成分更多，显得更明亮辉煌一些。

之后，笔者便步行前往三十三间堂，沿途顺路标指引，去了丰国神社和方广寺游览，景色亦不输一众热门景点。在闲步之余探索到这种小众佳境，也是野游的一大乐趣。三十三间堂本馆也是黑金系风格，室内陈列众多佛像与千手观音像，阵列密集有序，颇为震撼 `配合文字说明观看更佳`。而堂外以及外墙却又是朱红色为主，结合碧绿木水，与本馆相映成趣。个人认为是绝佳必去之境。

之后笔者又向清水寺走去，路过大谷本庙的时候进去看了一会。清水寺坐落在山上，对于笔者其主要趣味在于在日光照射下鲜亮的朱红楼阁，以及可一览京都城区的绝佳视角。由于已经见惯了黑色系建筑，笔者并没有买票进入付费区，而是转头向三年坂走去。三年坂其实是颇有唐长安城的韵味的，可惜彼时人流稠密，笔者后面翻看拍到的照片时才感觉到。

这之后又是一顿好走，其中路过的一家寺庙尤其吸引笔者的注意。寺名唤作大渐寺，被小道隔成两部分，中间以桥相连。小道一侧是寺庙唯一的楼栋，笔者到达时房屋主人正在笑着看他的子女嬉戏。另一侧是各家供奉的灵位。整个寺庙感觉就像是在居民区抠了两小片地修出来的，不过麻雀虽小五脏俱全，寺庙的基础功能 `包括御朱印` 都有。

转眼到了晚饭时间，实在懒得选的笔者直接去吃萨利亚了。令笔者惊奇的是，日本吃萨利亚的花费居然和国内差不多，大抵是除了便利店速战速决之外笔者吃过最便宜的了。吃完后笔者在京都A店逛了逛，不过感觉门面较小 `但还是比北京A店大多了，绷`，也没什么称心的东西。最后笔者去了伏见稻荷大社。伏见稻荷大社感觉主要看点在于爬山和千本鸟居。千本鸟居确实很不赖，不过由于时辰较晚笔者没有继续往上爬了。

笔者在奈良主要靠自行车四处游走。需要注意的是小红书上不少去年的帖子提到可以凭JR mini pass免费租借，但是笔者去的时候已经不行了，因为免费租借需要纸质票，但是JR mini pass已经只出售电子票了。笔者骑车直奔唐招提寺，一路上饱览奈良乡下风景。唐招提寺以及附近的药师寺都是比较小众宝藏的去处，不仅很有历史底蕴 `比如唐招提寺即是由鉴真和尚创立的，鉴真入灭后亦葬于此` ，风景不赖，游客还少，是极好的去处。

逛完后，笔者骑车转而往奈良公园方向而去。笔者先是去了汉国神社，这里供奉有将馒头传入日本的元朝人林丈荫，『汉国』之名大抵也是来源于此吧。之后笔者去了奈良公园看了看鹿，便又骑车往西边而去。笔者经过了平城宫历史遗迹，不过遗迹公园几乎没有建筑留存，没有什么看头，一路上主要还是看乡村风景。

笔者一路骑行，终于到达了奈良的小众巡礼圣地——山上彻也枪击安倍晋三处。此处与22年相比，已经有了一些变化，不过还是能够辨认出不少要素。现场看起来和日本的普通路口一样，不过笔者在一个花坛上发现了一个凭吊安倍的小杯植物，上面还写着自民党曾用过的竞选口号。经过一番巡礼后，笔者在奈良的行程也就结束了。笔者骑回奈良站后，便往宇治而去。

笔者到达宇治时已经较晚，只在梦浮桥古迹、平等院门口和宇治公园逛了逛就走了。另外比较巧的是，笔者在往梦浮桥走，思考吃什么时，一抬头又看到了萨利亚。于是笔者再次欣然在萨利亚开吃。

## 神人故逝



笔者原打算在新今宫站乘坐南海电铁去往关西机场，然而笔者一时昏了头，竟以为南海本线是JR路线，于是像往前几天一样直接从东口走进JR站了。进去之后笔者按照导航去了3站台，然后就坐上从机场往市区开的关空纪州路快速了，坐了好几站笔者才反应过来，又往回坐。南海电铁在JR的西侧，于是笔者就从西口出去了，没想到JR闸机不能处理同站进出，直接报错，而且由于缺失出站记录，笔者不能进入南海电铁。于是笔者找工作人员，工作人员说需要支付东进西出的150円。但是笔者微操把钱都充进了西瓜卡，除去坐南海电铁没有余钱支付，于是工作人员让我去东口出站。结果东口工作人员声称由于笔者停留时间太久，需要支付450円。此时笔者已急甚，匆忙认下这笔冤枉钱就跑去街对面的便利店取现钱 `因为沟槽的西瓜卡只能现金充值` ，并且喜扣220円手续费。当笔者终于忙活完回到西口时，最近的去往机场的班次已经开走，下一班车至少要二三十分钟。于是笔者绕了一大圈后，终于还是去1/2站台等关空纪州路了。

本以为这之后应该就没事了，结果列车要开到北信太站的时候突兀停车。笔者用翻译软件收听列车司机播报，说是因为自行车闯入轨行区 `其实感觉是自杀的隐晦说法`，正在进行轨道安全检查。列车停了四十分钟左右，才终于启动。行进十多分钟到达日根野站后，笔者本以为将要见证关西空港/和歌山方向的分离名场面了，结果列车在这站直接停止服务，把乘客都撵下车了。笔者也是没绷住，等不及就上了下一班去往关西机场的列车。上来之后一看发现不对，好像是要额外买特急券的Haruka，不过笔者心想就最后一站了，沟槽的JR想必不会刁难本人了吧。结果中途笔者昏昏欲睡的时候被乘务员催收了，喜扣760円。经过这一系列逝故后，笔者终于赶到了机场，此时距离航班起飞只有五十分钟左右了。在托运的时候差点又出乐子了，笔者到达香港航空的柜台发现大排长龙，想着果然还是完蛋了。结果一问发现队伍是后续其他航司的航班，其实笔者可以直接走上前去办理托运。最终，在经过安检大排队与出关手续后，笔者终于在航班起飞前25分钟到达了登机口。
